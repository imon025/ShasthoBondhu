# ShasthoBondhu – Health at a Glance, Friend at Heart
imonfarazi01@gmail.com-> supabase 
ShasthoBondhu is an AI-powered healthcare mobile application built with Flutter, designed to provide smart health assistance, disease detection, and nearby medical support — all in one platform.

## 📱 Overview

ShasthoBondhu aims to make healthcare more accessible through intelligent features such as:

- 🫁 Pneumonia Detection using AI (CNN Model)
- 😊 Emotion Detection
- 🩺 Skin Disease Detection
- 💡 Smart Health Suggestions
- 🏥 Nearby Hospital Finder
- 🌍 Multi-language Support (Bangla & English)
- 🔒 User-friendly and secure healthcare experience

## 🚀 Features

### 1. Pneumonia Detection
- Upload or capture chest X-ray images
- AI-powered detection using Convolutional Neural Networks (CNN)
- Instant prediction results
- Health recommendations based on results

### 2. Skin Disease Detection
- Detect common skin conditions using image analysis
- AI-based preliminary assessment
- Suggest possible precautions

### 3. Emotion Detection
- Analyze emotional state through facial input
- Provide mental wellness suggestions

### 4. Smart Health Suggestions
- Personalized health tips
- Symptom-based guidance
- Preventive care recommendations

### 5. Nearby Hospital Finder
- Find nearby hospitals using location services
- Interactive map integration
- Hospital details and directions

## ⚙️ Installation

### Prerequisites
- Flutter SDK installed
- Android Studio / VS Code
- Dart
- Emulator or physical device

### Clone Repository

```bash
git clone https://github.com/imon025/shasthobondhu.git
cd shasthobondhu
```

### Install Dependencies

```bash
flutter pub get
```

### Run App

```bash
flutter run
```
